## 🚀 **What I Work On:**
- **Bots**: Telegram bots in Python and PHP (media downloaders, multi-account tools, a lightweight PHP bot class) and Discord/order-management bots in JavaScript.
- **Websites**: portfolio and author sites built with HTML, CSS/SCSS, JavaScript and TypeScript.
- **Tools & Automation**: backup and monitoring tools, PowerShell scripts, and dependency maintenance (e.g. a secure unzip shim for eDEX-UI).

- **Automation**: scripts and services that handle repetitive server and project tasks.
- **Legacy Code**: revitalizing older codebases and keeping them up to date.
