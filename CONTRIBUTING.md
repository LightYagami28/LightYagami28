# Contributing

Grazie per l'interesse a contribuire. Prima di aprire una PR:

1. Apri una issue per discutere il cambiamento (per modifiche non banali).
2. Lavora su un branch dedicato, mai su `main`/`master`.
3. Commit piccoli e firmati GPG, messaggi in italiano, chiari.
4. Mantieni lo stile del codice esistente e aggiungi/aggiorna i test quando possibile.
5. Verifica che build e test passino prima di aprire la PR.

Le PR verranno riviste; potrebbero essere richieste modifiche. Grazie.
